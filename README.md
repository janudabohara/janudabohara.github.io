# Januda Bohara — editorial portfolio

Static Astro portfolio using Tailwind and small React islands. The visual source of truth is the Figma file [Januda Bohara — Matte Glass Editorial Portfolio](https://www.figma.com/design/c0tsAqB9rOoatx00RMKbPL).

## Commands

- `npm run dev` — local development
- `npm run build` — Astro type check and production build
- `npm run preview` — preview the production output

## Content

Publish real entries as Markdown in `src/content/technical-work`, `src/content/field-notes`, or `src/content/journal`. Draft entries are excluded from archive, detail, RSS, and sitemap output.

External profile destinations live in `src/config/site.ts`. Destinations without verified URLs are deliberately omitted from production.
